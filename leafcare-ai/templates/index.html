About LeafCare AI

Bridging Machine Learning & Precision Agriculture

Problem Statement & Motivation

Foliage diseases account for up to 40% of agricultural crop yield losses annually. Traditional visual inspection by farmers often suffers from misdiagnosis, delayed treatment, or indiscriminate pesticide overuse. LeafCare AI provides an instant, accurate, and accessible diagnostic companion that classifies foliar symptoms and suggests targeted organic/chemical countermeasures.

Academic Objective: Implement a production-grade Convolutional Neural Network integrated with a lightweight Flask web service and relational persistence.

System Architecture

Frontend

HTML5, Responsive CSS3, Vanilla ES6 JavaScript

Backend Service

Python Flask REST API with Secure File Validation

Neural Classifier

TensorFlow / Keras MobileNetV2 Deep CNN Model

Database

SQLite3 Audit Logging with JSON Remedy Mapping

Dataset & Deep Learning Pipeline

  • Dataset Source: PlantVillage Benchmark Dataset (Penn State University & EPFL).
  • Input Dimension: 224 × 224 × 3 RGB tensor channels.
  • Data Augmentation: Random horizontal flip, rotation (±20°), zoom range (0.2), and contrast scaling.
  • Optimization: Adam Optimizer with categorical cross-entropy loss and learning rate scheduling.
  • Evaluation Metrics: True Test Accuracy, Macro F1-Score, Precision, and Recall on isolated test split.
